# Design a factory layout

For a named, team-shared factory whose additions/deletions update inventory, use the [named factory workflow](named-factories.md) from Overview. The **Factory layouts** tool below retains personal layout studies of existing inventory; it does not create or delete inventory records.

Open **Tools & settings → Factory layouts**. Start an empty floor or use the current factory arrangement. Name the layout, set its width and depth in metres, and add named rectangular zones. Place authorized equipment from the palette, grab and drag it directly, or use arrow keys to make small adjustments. The rotation field sets each selected item's orientation.

In 3D, **Rotate is off by default**. Moving the mouse without pressing a button leaves the view still. To pan left/right or up/down, press and hold the left mouse button on empty floor and drag; release to stop immediately. A click followed by release does not keep panning active. Turn **Rotate on** to orbit with mouse movement without pressing. Rotation follows the hand and stops when it stops; leaving the floor stops it too. Pressing to grab pauses hover rotation, so equipment stays steady while being placed. Turning Rotate off returns to grab-only panning without resetting the view.

An item is grabbed only when the pointer hits its visible equipment geometry; nearby space, labels, status dots, shadows and selection rings are not enlarged grab areas. Zoom in for small parts, or select from the item list and use the arrow keys. Touch gestures and the floor plan retain their existing direct manipulation. The hand cursor closes while you hold an item or empty floor. Drag equipment to reposition it, or drag empty floor to pan the view; release to drop. With the canvas focused, hold Space while dragging to pan even when the pointer is over equipment. Right-drag or Shift-drag rotates the 3D camera, and scrolling or pinching zooms. Escape cancels an item grab; a click selects its details. Double-click a machine to bring its detailed model into focus. **Fit** returns to the complete floor. The separate **Enter fullscreen** icon expands the live floor and controls to the screen; use **Exit fullscreen** or Escape to return. The same view and equipment positions are retained. Browsers that cannot enter native fullscreen expand the floor within the browser window. Compact icons switch between 3D and the floor plan, fit the view and reset the overview arrangement; hover for their labels. The accessible floor plan also supports panning, item dragging and keyboard placement when 3D is unavailable. Equipment footprints are illustrative; saved coordinates do not move machinery.

An individual account's **Save layout** stores a version owned by that user and data workspace. Reopen a saved layout to continue, save a separate copy, or archive and restore it. Concurrent saves reject stale versions so another tab's newer work is preserved. Only currently authorized equipment can be saved. Layouts do not alter inventory identities, telemetry or commissioning records.

Shared demo visitors save personal drafts in their own browser. These drafts survive refresh and demo role switches, can be reopened and downloaded as JSON, and include equipment created in the [editable demo](editable-demo.md). Browser drafts are limited to 50 layouts. Remove a browser draft to free space, and use Undo to restore it if needed; removing a browser draft does not delete an account save. Use Download layout if browser storage is unavailable or before clearing site data. Clearing site data removes local drafts; a different browser starts a separate workspace. Resetting demo equipment retains layout drafts and marks removed custom equipment unavailable.


## Loading, storage, production and exits

The 3D floor and accessible plan include inbound/loading, warehouse/inventory storage, production and outbound/exit areas. Loading and exit bays have open door frames and directional markings; storage uses illustrative racks and cartons. These are layout context, separate from registered equipment and stock records.

Use **Add zone**, then choose or type a suggested purpose such as **Inbound / loading**, **Warehouse / inventory**, **Production / assembly** or **Outbound / dispatch**. Adjust the existing zone position and dimensions to match the factory. The matching area follows those saved coordinates; loading/exit doors use the nearest boundary, including a real opening in the cutaway wall. Zone names stay editable. If a purpose has no named zone, a reference area supplies context at the perimeter. Default storage avoids configured loading openings.

The architectural graphics illustrate the layout and add no equipment records or stock quantities.
