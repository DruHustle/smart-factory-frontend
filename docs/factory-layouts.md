# Design a factory layout

Open **Tools & settings → Factory layouts**. Start an empty floor or use the current factory arrangement. Name the layout, set its width and depth in metres, and add named rectangular zones. Place authorized equipment from the palette, grab and drag it directly, or use arrow keys to make small adjustments. The rotation field sets each selected item's orientation.

The hand cursor closes while you hold an item or empty floor. Drag equipment to reposition it, or drag empty floor to pan the view; release to drop. Hold Space to pan even when the pointer is over equipment. Right-drag or Shift-drag rotates the 3D camera, and scrolling or pinching zooms. Escape cancels an item grab; a click selects its details. **Fit** returns to the complete floor. Compact icons switch between 3D and the floor plan, fit the view and reset the overview arrangement; hover for their labels. The accessible floor plan also supports panning, item dragging and keyboard placement when 3D is unavailable. Equipment footprints are illustrative; saved coordinates do not move machinery.

An individual account's **Save layout** stores a version owned by that user and data workspace. Reopen a saved layout to continue, save a separate copy, or archive and restore it. Concurrent saves reject stale versions so another tab's newer work is preserved. Only currently authorized equipment can be saved. Layouts do not alter inventory identities, telemetry or commissioning records.

Shared demo visitors save personal drafts in their own browser. These drafts survive refresh and demo role switches, can be reopened and downloaded as JSON, and include equipment created in the [editable demo](editable-demo.md). Browser drafts are limited to 50 layouts. Remove a browser draft to free space, and use Undo to restore it if needed; removing a browser draft does not delete an account save. Use Download layout if browser storage is unavailable or before clearing site data. Clearing site data removes local drafts; a different browser starts a separate workspace. Resetting demo equipment retains layout drafts and marks removed custom equipment unavailable.
