# Product experience and trusted evidence qualification

Date: 27 October 2026. This report covers the implemented feature branches and disposable software acceptance. Production has not been merged or deployed by this work. The P0 access fix is therefore not yet active in the public deployment.

## Visible product changes

The shared orange/white/cyan theme now carries through Overview, inventory and contextual item workspaces, Monitoring, process investigations, native cybersecurity, Analytics, Assistant, Administration, notifications and firmware inventory. Both themes use shared headers, controls, forms, state labels, filters and responsive navigation. No site/tenant model was invented.

The first viewport leads with useful work: attention items and fleet state on Overview; search and immediately useful inventory/Monitoring cards on mobile; a selected investigation on desktop Alerts; observed analytics or one compact no-data state; a readable Assistant conversation with expandable evidence. Administration keeps Users & access, Integrations, Audit trail and Workspace in one local navigation system. Registration separates identity, route, representation, review and commissioning. Unsupported updates and advanced metrics remain explicitly unavailable.

Native 3D retains the existing detailed 87-entry assembly and geometry. The viewer, tree and inspector share selection; mobile sheets, grouped inspection controls, saved views and the BOM fallback preserve explosion, reassembly, section caps, ghost housings and component evidence. Nothing in navigation, refresh or viewer interaction commands equipment.

Completed journeys include Overview → inventory → contextual telemetry/AAS/3D/security → return to filtered results; direct IoT and gateway routes; search → process investigation → assign/note/explicit downtime/resolve → owner notifications; cybersecurity evidence → finding → investigation/recurrence → mapped component; private passport preview → explicit publication → revocation; registration and commissioning edits; and individual administrator recovery → first password change → revoke/disable/re-enable.

## Operating boundaries

This is reviewable code and disposable software qualification. Production still requires its normal authorized merge/promotion and an API-first rollout with a retained compatible hardened rollback target. A prior pre-hardening .NET 8 image is not a qualified rollback target.

Physical machinery/collectors, real mobile GPU performance, actual background-tab behavior on a deployed browser, managed broker MQTT 5/TLS/ACL changes, an actual Onesa consumer, real email delivery and production backup/restore acceptance were not performed. No firmware was flashed, real command sent, real email retried, plant policy changed or private evidence sent to an LLM. OEE/RUL/predictions/calibrated energy/emissions remain unavailable without their required inputs; commanded state is not measured feedback.
